# Aruna Tulis — concept demo

Self-initiated one-page website concept for a fictional contemporary batik tulis atelier in Pati, Jawa Tengah. This is **not a real business**. There are no real clients, reviews, testimonials, or statistics.

**Concept demo by Yeyen Muhidin**, web designer from Pati, Indonesia. Intended as a sample for freelance profiles (Fiverr, Upwork, Sribu, and similar).

Open `index.html` in a browser, or serve the folder with any static file server.

## Fonts

- [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) by Tokotype, SIL Open Font License 1.1
- [Fraunces](https://github.com/undercasetype/Fraunces) by Undercase Type, SIL Open Font License 1.1

Subset variable fonts are included in `fonts/`.
